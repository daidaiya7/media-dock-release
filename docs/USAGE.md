# 使用指南

## 首次部署

按 [README](../README.md) 启动后，先通过本机或 SSH 隧道进入 `/admin` 初始化管理员。系统没有通用初始密码，首次初始化至少需要 8 位密码；建议使用密码管理器生成的独立长密码。未经初始化的站点不要提前暴露公网。

本站是观影服务门户，播放由媒体服务器和播放器完成。部署本站不会自动安装 Emby、NextEmby、NextFind，也不会自动获得片源或 CDN。

## 运营配置

**影视库**：连接自有 Emby 服务并选择公开展示范围。前台预览不是播放授权，实际播放仍以媒体账号权限为准。后台凭据应只授予集成需要的权限，优先使用专用账号或 Token。

**求片**：连接自己的 NextFind 后再启用相应入口。访客申请需要管理员处理；申请成功不代表影片已经入库。站点不附带第三方用户中心桥接部署。

**套餐与订单**：初始套餐全部禁用。检查 NextEmby 模板名称、天数和交付方式，填写自己的价格、说明及购买入口后再启用。页面登记或“已付款”提示不是支付平台到账证明，管理员应完成核对后再批准发卡。闲鱼与小红书适配模块随代码保留，但默认不连接任何账号；部署者必须在自己的环境中填写账号、商品、代理和凭据。

**领取链接**：链接本身是领取凭证，持有人可以查看对应卡密。请单独发送给对应买家，不要放到公开群、公开公告或可转发页面。当前链接可重复使用，并无短期自动失效保证。

**公告**：在管理后台编辑简介入口名称、公告标题和段落。根据实际部署修改文案，不要保留与实际线路、硬件或服务能力不符的宣传。

**TMDB 内容**：配置自己的 TMDB 凭据并检查缓存刷新。首次获取需要服务器能访问上游；客户端和服务端的网络条件不同。热门影片展示不等于片库已收录。

**线路监测**：浏览器测速是用户至测试地址的 HTTP 响应时间，包含 TLS、CDN、源站与服务处理等因素。使用支持直接响应、无需登录、不跳转的小型 HTTPS 静态资源；不要用播放接口或带账号 Token 的地址。它不能代替实际播放测试，也不是网络 ICMP Ping。

## 定时更新

Compose 同时启动门户与 `scheduler` 定时服务，共用数据和凭据卷。监测每分钟采样；TMDB 已启用且配置凭据后，每天 06:10 刷新，时区由 `MEDIADOCK_TIMEZONE` 指定，默认 Asia/Shanghai。首次启用或停机错过更新后会补刷；上游失败保留原缓存，并每五分钟重试。可使用 `docker compose logs --tail=100 scheduler` 查看运行记录。

默认精简镜像没有安装 ICMP ping 工具，ICMP 项会显示不可测；容器部署请优先选择 HTTP/HTTPS 或探针监测。浏览器测速由访问者手动发起，不由定时服务代测。

## 更新与备份

正式升级前，同时备份数据和凭据。默认使用 Docker 命名卷，实际卷名可在 `docker volume ls` 中查看。下面从停止后的容器中导出一致的备份：

```sh
mkdir -p backups
chmod 700 backups
docker compose stop
docker compose cp mediadock:/var/lib/mediadock/data ./backups/data
docker compose cp mediadock:/var/lib/mediadock/secrets ./backups/secrets
chmod -R go-rwx backups
docker compose start
```

每次使用新备份目录，避免覆盖唯一可恢复版本。备份内含客户数据和有效密钥，应加密离线保存，不能上传 GitHub。上面的流程需要维护窗口。不要只复制运行中的 SQLite 主文件；未落盘内容可能仍在 WAL 中。

镜像分发升级：将 `.env` 的 `MEDIADOCK_IMAGE` 改成新的版本标签或摘要，再执行：

```sh
docker compose pull
docker compose up -d
docker compose ps
```

保留旧镜像版本及对应备份。数据库结构可能随版本变化，回退应根据该版本说明恢复匹配的数据与密钥。恢复后检查目录归属 `10001:10001`、凭据目录 `0700` 和文件 `0600`，再验证登录、旧订单查看与测试卡密领取。

## 常见问题

| 现象 | 检查项 |
| --- | --- |
| 提示访问地址未配置 | `.env` 的 `MEDIADOCK_PUBLIC_BASE_URL` 是否与浏览器地址完全匹配，代理是否保留 Host |
| HTTPS 下操作被拒绝或登录反复失效 | 代理是否覆盖 `X-Forwarded-Proto`，实际代理 IP 是否列在 `MEDIADOCK_TRUSTED_PROXIES` |
| 凭据目录不可用 | 目录是否属于 UID 10001，权限是否为 0700，文件是否为 0600，路径是否含符号链接 |
| 卡密无法解密 | 是否遗漏原 `mediadock-secrets` 卷，是否把其他实例的密钥与数据库混用 |
| 页面没有可购套餐 | 默认模板全部禁用，请先检查并启用自己的套餐 |
| 接口地址中的 localhost 无法访问 | 容器内 localhost 指向容器自身，请填写容器能访问的上游地址 |
| 服务健康但无法播放 | 健康检查仅验证门户；另查媒体账号、播放器地址、CDN 与片源 |

故障反馈时可附版本、错误时间及已脱敏的报错信息；不要发送密码、API Token、Cookie、完整领取链接或客户卡密。
