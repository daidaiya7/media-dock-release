# 部署者配置清单

所有实例独立配置，不附带原站点的服务地址、域名、Token、账号或业务数据。示例域名均不可作为实际服务使用。首次部署先在本机初始化管理员，再开放公网入口。

| 项目 | 填写位置 | 初始状态 |
| --- | --- | --- |
| 本站域名 | `.env` 的 `MEDIADOCK_PUBLIC_BASE_URL` | 本机地址 |
| 管理员用户名 | `.env` 的 `MEDIADOCK_ADMIN_USERNAME` | `admin`，建议修改 |
| 管理员密码 | 首次初始化页面 | 无通用密码 |
| NextEmby 地址 | `.env` 的 `MEDIADOCK_NEXTEMBY_URL` | 示例域名 |
| NextEmby Token | 管理后台凭据设置 | 未配置 |
| Emby 地址与 Token | 管理后台影视库配置 | 未配置 |
| NextFind 地址与凭据 | 管理后台求片配置 | 未配置 |
| TMDB 凭据 | 管理后台热门影片配置 | 未配置 |
| 用户中心与卡密兑换入口 | 管理后台站点设置 | 未配置 |
| CDN / 测速 / 监测地址 | 管理后台线路监测 | 未配置 |
| 套餐、价格、模板和商品规格 | 管理后台套餐设置 | 示例套餐禁用 |
| 闲鱼账号、商品及代理 | 闲鱼模块设置 | 使用自己的配置 |
| 小红书账号、代理及工作进程 | 小红书模块设置 | 使用自己的配置 |
| 支付与购买入口 | 管理后台站点/套餐设置 | 未配置 |

环境变量修改后执行 `docker compose up -d`。后台保存的集成配置按页面提示生效。各项集成分别验证连接，不能仅依据容器健康状态判断发卡、订阅或播放可用。

Docker 中凭据写入独立 secrets 卷，不打包进镜像。不要将该卷复制给其他部署者。闲鱼、小红书的外部服务与账号登录仍需要自行准备，门户容器不会自动提供这些账号或外部服务。

## 发布前确认

只上传新整理的目录，避免把原工作目录及其 Git 历史一起推送。公共 GitHub 页面可使用仅含文档与部署文件的发行目录；含 `portal/` 的完整目录只保存到 Private 仓库。

不要提交 `.env`、secrets、业务数据库、订单/卡密、平台 Cookie、领取链接、备份或日志。文档截图也应使用演示数据。构建镜像前确认 Docker 排除规则仍生效，且没有手动复制任何运行时配置到程序目录。
